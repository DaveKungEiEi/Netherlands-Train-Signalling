Netherlands Train System — ATB → ERTMS/ETCS
====================================

เว็บไซต์หลายหน้าเกี่ยวกับการเปลี่ยนผ่านระบบอาณัติสัญญาณรถไฟทางไกลของเนเธอร์แลนด์

ไฟล์หลัก
- index.html       หน้าแรก + ประวัติ Nederlandse Spoorwegen (NS)
- atb.html         1.1 ATB คืออะไร / 1.2 ประวัติ / 1.3 หลักการทำงาน
- ertms.html       2.1 ERTMS/ETCS คืออะไร / 2.2 ประวัติ / 2.3 หลักการทำงาน
- status.html      3.1 สถานะการเปลี่ยนระบบ (อัปเดต 26 สิงหาคม 2026)
- problems.html    3.2 ปัญหาและความท้าทาย
- comparison.html  4.1 เปรียบเทียบเนเธอร์แลนด์–เบลเยียม–เยอรมนี
- impact.html      4.2 ผลกระทบต่อรถไฟทางไกล
- other.html       Glossary + แหล่งอ้างอิง
- styles.css       Liquid Glass + Netherlands Railway Theme + Responsive
- script.js        Navigation, mobile menu, reading progress, reveal animation
- favicon.svg      ไอคอนเว็บไซต์

วิธีเปิด
1. แตกไฟล์ ZIP
2. เปิด index.html ด้วย Chrome / Edge / Firefox
3. ไม่ต้องติดตั้ง package หรือ framework ใด ๆ

หมายเหตุ
- เว็บไซต์เป็น Static HTML/CSS/JavaScript และทำงานได้โดยไม่ต้องมี server
- ลิงก์แหล่งข้อมูลภายนอกต้องเชื่อมต่ออินเทอร์เน็ต
- ข้อมูลสถานะโครงการเป็นข้อมูลสาธารณะที่ตรวจสอบถึงวันที่ 26 สิงหาคม 2026
- ตัวเลขของเบลเยียม 79% ระบุชัดเจนว่าเป็นสถานะ ณ 31 ธันวาคม 2024 และไม่ถูกนำเสนอว่าเป็นตัวเลขปี 2026
